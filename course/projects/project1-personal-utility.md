# Project 1: Personal Utility App (Claude Web Artifact)

**Weight:** 15% of final grade
**Due:** Week 6

## Objective

Master the Claude Web harness by building a real solution to a validated problem as a Claude artifact. Learn effective AI collaboration through iterative prompting and refinement.

## Requirements

### Approval Requirement
- **Project idea must be approved by the professor on the #projects Slack channel at least one week before the deadline**
- Post your idea with: problem description, target users, and proposed user stories
- Wait for explicit approval before proceeding with full development

### Functional Requirements
- Solves a validated real problem (Mom Test interviews)
- 5+ user stories with working CRUD operations
- Data persistence (localStorage or browser storage)
- Responsive design (mobile + desktop)

### Technical Requirements
- **Claude Web artifact implementation** (React-based)
- JavaScript/TypeScript
- All functionality contained within the artifact
- No external deployment required—artifact link is the deliverable

### Documentation Requirements
- Complete chat history showing development process
- Problem statement with validation evidence
- User stories with acceptance criteria
- 500-word reflection on AI workflow
- 5-minute demo video

## Deliverables

Students must submit a **single PDF/document** containing:

1. **Artifact Link** — Shareable Claude artifact URL (must be accessible to graders)
2. **Chat History** — Complete Claude conversation used to build the artifact
   - Include all prompts and responses
   - Show iterative development process
   - Demonstrate debugging and refinement
3. **Problem Statement** — Clear description of the validated problem being solved
4. **User Stories** — 5+ user stories with acceptance criteria
5. **Reflection** — 500-word reflection on AI workflow and what worked/didn't work
6. **Demo Video Link** — 5-minute YouTube/Loom walkthrough demonstrating all features

| Category | Points | Description |
|----------|--------|-------------|
