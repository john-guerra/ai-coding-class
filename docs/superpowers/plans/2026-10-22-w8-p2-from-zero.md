## Review Focus

1. **Search input from users:** empty or whitespace-only `q`, `q` over 200 chars, and websearch operators/quotes (`"graph`, `-`, `OR`) → API returns 400 for the first two and never 500 for any; page shows a friendly message. Tests in Task 6.
2. **Database unreachable or misconfigured env vars** → API returns 500 with `{ error: "Search is unavailable" }`, no stack trace or key leak; page shows the same message. Test in Task 6.
3. **Dirty CSV rows** (missing year, empty abstract, duplicate DOI) → seed skips or upserts without aborting the whole load, and reports counts. Test in Task 6.
4. **CI on a fork / without secrets** → workflow still passes lint, unit, build; DB-backed tests run against a local Supabase started in the job, never against production. Checked in Task 5/6.
5. **Broken links on slides** → every `tree/step-N-*` URL resolves (HTTP 200) before the deck is called done. Check in Task 9.
