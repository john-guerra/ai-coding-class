# Master Prompt for Claude PowerPoint Plugin

Paste this entire prompt into the Claude PowerPoint plugin to generate the presentation.

---

Create a professional 9-slide PowerPoint presentation for a university course recruitment event called "Preview Night." The presentation is for **CS 7180: Vibe Coding — AI-Assisted Software Engineering**, Fall 2026, at Northeastern University's Silicon Valley campus.

**Design guidelines:**
- Widescreen 16:9 format
- Primary brand color: Northeastern red (#CC0000)
- Dark slides for title, outcomes, and CTA (dark navy #1A1A2E background with white text)
- Light slides for content (white background with dark text #333333)
- Thin red accent bar at the top of every slide
- Clean, modern, professional look — Calibri or similar sans-serif font
- Use visual hierarchy: large titles (44pt), body text (20-22pt), details (16-18pt)
- Minimal text per slide — this is a 5-minute pitch, not a reading assignment
