# Image Prompts for Preview Night Presentation

Use these prompts with Gemini (or any image generator). Target aspect ratio: **16:9** (widescreen slides).

## Slide 1: Title Background

**Prompt:**
A modern developer workspace seen from above at a slight angle. A laptop screen shows colorful code with subtle glowing AI suggestion highlights appearing inline. Around the laptop: a coffee cup, sticky notes with architecture diagrams, and a small robot assistant figurine. The scene has warm, inviting lighting with a clean dark desk. Style: digital illustration, slightly stylized, professional but approachable. Color palette includes Northeastern red (#CC0000) accents. 16:9 aspect ratio.

## Slide 2: Vibe Coding vs Professional AI Engineering

**Prompt:**
A split-screen illustration comparing two developer scenarios. LEFT SIDE labeled "Vibe Coding": a developer casually typing prompts into a chatbot, surrounded by messy code snippets, error messages, and a "it works on my machine" sticky note — chaotic but fun energy. RIGHT SIDE labeled "AI Engineering": the same developer now with a professional setup — clean code on screen with green test checkmarks, a CI/CD pipeline visualization, monitoring dashboards, and a deployed application badge. The right side feels polished and confident. Style: flat vector illustration, playful but clear contrast. 16:9 aspect ratio.

## Notes

- All images should be 16:9 for widescreen PowerPoint slides
- If any image has text in it, it should be minimal — the actual text will be added in PowerPoint
- Prefer illustrations over photorealistic — they scale better and look more professional in presentations
- Northeastern red: #CC0000 / RGB(204, 0, 0)
